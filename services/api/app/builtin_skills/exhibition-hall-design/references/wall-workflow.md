# 墙面规划和阶段规则

## 墙面怎么计数

- 统计对象是“可独立承载展陈设计的展示面”，不是三维模型里所有几何面。
- 建筑直墙、折墙的独立段、弧形展墙和独立展墙分别编号；连续同材质同内容且没有结构分隔的墙面可合并。
- 独立展墙正反两面都承担内容时用 `W05-A`、`W05-B`；只设计一面时只登记该面。
- 柱体、门洞侧壁、设备面和屏幕载体只有在用户范围内才计入；入口门洞本身不默认算墙。
- 单张透视图看不到的背墙、转角后方和遮挡面标为候选，不把推测写成确定数量。尺寸只采用标注、模型元数据或用户确认值。

建议台账字段：

| 字段 | 内容 |
| --- | --- |
| wallId | 稳定编号 |
| type | 建筑墙、独立展墙、弧墙、柱面或其他载体 |
| location | 相对入口、动线或相邻墙的位置 |
| dimensions | 已知长度、高度及来源；未知值为待确认 |
| faces | 正面、背面或双面 |
| narrativeRole | 序厅、章节导入、核心展项、互动、转场或结语 |
| content | 标题、正文、图片、文物、视频、互动和实物展项 |
| source | 文档定位、图片资产或用户消息 |
| treatment | 图文墙、展柜、屏幕、装置、灯箱、实物或混合形式 |
| constraints | 门洞、消防、设备、观看距离、不可遮挡内容和待确认项 |

## 文档内容怎么映射

1. 先按文档原有标题和章节形成内容树，再识别实物、图片、视频、地图、音频和互动素材。
2. 按参观顺序分配“导入 → 展开 → 核心 → 转场 → 总结”，避免只按段落长度机械切墙。
3. 大墙承载章节导入、时间线、地图或多媒体组合；短墙和折墙适合单件重点展项；弧墙适合连续叙事或沉浸画面，但不强行塞入大量精确正文。
4. 一条内容可跨墙时记录连续关系；一面墙过载时拆分内容，不通过缩小文字掩盖容量问题。
5. 文档中的内嵌图片先定位和查看；只有确认要进入展陈画面时才提升为项目资产。来源、版权、清晰度或替换状态不明时写入台账。

## 整体母版怎么锁定

- 用户确认的整体效果图是逐墙深化的唯一视觉母版，不是可选风格参考。多张互补视角只有在属于同一版方案并同时获确认时才组成母版组。
- 为每个展示面记录 `wallId → masterAssetId → 可见区域/视角`。墙面在母版中未出现、被严重遮挡或无法唯一对应时，标为阻塞，不进入逐墙生成。
- 锁定项至少包括主辅色关系、墙体背景与饰面材质、主视觉图形及比例、模块网格与留白、标题/正文层级、线框与圆角语言、屏幕/展柜/展品的位置尺度、灯光色温与重点照明关系。
- 允许变化仅包括把对应墙面转成便于审阅的视角、必要裁切与遮挡消除、提升清晰度，以及在母版已经预留的模块中补足台账里的准确图文。新增模块、改色、换材质、改变图形比例或移动陈设都属于母版变更。
- 每面墙都直接追溯到同一母版组；不得让 W02 复制 W01、W03 再复制 W02 形成逐步漂移。相邻墙结果只可用于连续图形的接缝核对。

## 两阶段交付

### 第一阶段：整体效果

- 交付墙面台账文本节点和用户要求数量的整体空间效果图；未指定时优先一张覆盖主要空间关系的总视角，输入中存在互补且必要的机位时可生成对应视角。
- 图像提示词应包含已确认的墙面编号与主题关系、空间保留项、统一材质、主辅色、灯光、屏幕和展项位置。整体视角必须让后续范围内的每面墙至少在一张图中可辨认；需要多张互补视角时保持同一版方案。
- 整体效果用于确认空间、叙事和风格，不声称其中长段文字可直接生产。准确标题、说明文字和素材清单仍以台账为准。
- 交付后列出每面墙对应的整体视角并停止，等待明确确认。逐墙项可以记录为后续范围，但不能在本阶段启动生成。用户确认后保存实际母版资产和版本；不能只保存视觉描述。

### 第二阶段：逐墙深化

- 每个展示面是独立交付项，标题带稳定编号，例如“W03 古代交流墙效果图”。
- 优先使用正视或轻微透视、无遮挡、能看清完整边界的视角；需要表达空间关系时再补充近景透视。
- 每次生成都同时使用对应未设计底图作为 `edit` 或 `layout`，并使用同一已确认整体母版真实资产作为 `identity`。逐项 `preserve` 写全锁定项，提示词明确“提取并转正这一面墙，不做新的设计方案”。不得仅复述母版风格，也不得重新使用原风格参考取代母版。
- 对双面墙分别生成并核对 A/B 面；连续墙面核对跨墙图形和叙事顺序；屏幕、展柜和实物的位置、尺度、材质与整体图一致。母版未显示的一面先补整体视角并确认。
- 用户只要求部分墙面时只生成该范围，不补做其余墙面。

## 变更与验收

- 文档新增、删除或改写内容时，以内容来源定位受影响墙面，保持其他墙面不变。
- 用户否决整体方向，或任何修改会影响共享锁定项时，修改整体图并重新确认；不要在旧母版或未确认方向上继续扩散到逐墙图。
- 核对墙面编号、数量、主题、尺寸来源、内容完整性、动线顺序、实际母版资产 ID/版本、屏幕与展柜位置，以及锁定项是否逐项一致。任何墙面若未传入对应母版或出现视觉漂移，保持待核实，不计入完成数量。
- 未明确要求改变的建筑结构、文字、Logo、展品、构图和装饰应保留；修改结果始终生成新节点，不覆盖原图。

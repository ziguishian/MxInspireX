# 纸质笔记本的图像与印刷检查

先确定成品尺寸与装订方式，再采用厂家对应模板。展开尺寸、打孔边、书脊和拼版依据实际纸材及工艺数据确定；资料待补充时，先交付效果方案并列明待确认项。

A5 线圈本单面封皮示例：成品 148×210 mm，四边出血 3 mm，含出血页面 154×216 mm，安全边距 5 mm。具体数值以承印方要求为准。

有效清晰度按实际像素 ÷ 成品英寸核算。以 300 ppi 为工作目标，154×216 mm 约需 1819×2551 px；检查原图与裁切后的可用像素，记录实际达到的清晰度和细节水平。

封面、封底和约定内页分别由图像模型生成，提示词包含成品比例、出血延展、安全区和准确文字，并引用确认的母版。保存后核对实际图像；裁切、装订、页序及尺寸要求写入制作说明，工艺精度按测量和厂家确认结果记录。

检查文字位于安全区内、背景覆盖出血、内页线条清晰、装订边留白合适、样机引用实际页面。图中文字合成为像素，准确文案另以文字保留。

交付独立封面图、封底图、约定内页图、样机图和所需规格说明。纸张、色彩模式、专色、烫金、模切和印前处理由印厂确认。

# 笔记本图像设计

用图像模型分别生成封面、封底和样机，逐张交付 PNG/JPEG/WebP。阅读[执行映射](references/host-tools.md)；涉及印刷规格时参考[印刷检查](references/print-spec.md)。

1. 确定成品尺寸、装订方式、页面范围和已有品牌素材。偏好待定时说明设计假设并先做效果方案；展开尺寸和书脊依据对应装订工艺及厂家数据确定。
2. 生成正视平面的完整封面母版，包含约定标题、图案与版式。提示词写明准确文字、安全区域、主题、配色和构图，保存真实资产 ID。
3. 引用封面母版另行生成封底，延续配色与图案语言，设计适合封底的构图和文案。封面、封底各对应一个交付项和一张独立图片。
4. 引用实际封面图片生成装订、材质与使用场景样机；展示封底的角度同时传入封底图片。用户需要内页时，生成约定页型并核对线距、留白与装订边。
5. 有打印需求时，按实际像素和成品尺寸核算清晰度，附出血、安全边距及待印厂确认的规格；具体方法见印刷检查。
6. 由系统对本轮节点缩略总览统一审查一次，检查页面顺序、整体图案与边距；细小文字和印刷精度看不清时列为待核实。不逐图放大、不自动修复或复审，保留图片供查看下载，准确文案与制作说明按需以文字交付。

完成条件：约定页面和样机齐全、视觉一致、文字准确、图片可分别下载，印刷规格状态清楚。

# 场景、用途与载体矩阵

先确定使用场景和目的，再结合行业选择载体。每项推荐附一句实际用途；同一种载体可以按用途呈现不同设计。整套采用同一品牌档案，行业切换时按新的业务语境重建推荐。

| 场景 | 主要用途 | 候选载体 |
|---|---|---|
| 门店与服务现场 | 品牌识别、服务体验 | 门头、前台、菜单、服务卡、员工服装 |
| 产品销售与交付 | 产品识别、信息说明 | 包装盒、瓶身或罐身、标签、封口贴、手提袋 |
| 开业、上新、推广 | 传达主题、吸引关注 | 主视觉、海报、展架、线上宣传图 |
| 展会与线下活动 | 品牌展示、现场识别 | 展位背景、胸牌、资料封面、活动袋 |
| 商务沟通 | 专业形象、信息传递 | 名片、信纸、文件夹、演示封面 |
| 节庆与客户礼赠 | 表达心意、强化记忆 | 礼盒、贺卡、包装纸、礼品袋 |
| 社交媒体运营 | 持续传播、内容识别 | 头像、主页封面、栏目封面、图文版式 |
| 办公与组织内部 | 身份识别、品牌归属 | 工牌、工作服、办公标识、内部资料封面 |

## 行业适配

- 咖啡茶饮：优先考虑杯身、杯套、外带袋、封口贴、菜单和门头。
- 餐饮：餐盒、餐具套、纸巾包装、菜单和围裙。
- 活动与公共空间：入场券、导览手册封面、主题包装、活动袋和工作人员标识。
- 酒店民宿：房卡、卡套、门牌、洗护包装、迎宾卡和前台。
- 美妆个护：瓶身、外盒、标签、购物袋和陈列台。
- 科技与企业服务：名片、工牌、资料封面、演示封面、办公标识和展位。
- 工业制造：产品铭牌、设备标识、工作服、产品手册封面、运输包装和展会应用。
- 服装零售：吊牌、织标、购物袋、包装纸、会员卡和陈列。

按用户的具体产品与经营方式筛选候选项，实际选择以本次用途为准。实体空间类目适用于品牌具有对应场地的场景，图案和文案使用当前行业的内容。

## 视觉与工艺检查

提示词包含载体用途、原 Logo、固定字标、辅助图形、标准色、材质工艺、镜头光线、准确文字和版面位置。纹理作用于载体，原 Logo 保留原始版本；单色和反白应用采用已授权版本。

名片检查字距与留白；袋体检查折边、提绳与图形完整性；包装检查版面连续性与工艺位置；门头检查安装比例和远读性。标准色保留用户原始色值，场景色彩结合光照与材质核对，制作规格以实际工艺资料为依据。

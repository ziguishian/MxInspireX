# Logo 样机与品牌延展

以用户提供的 Logo 为母版，用图像模型制作辅助图形与场景应用，逐张交付 PNG/JPEG/WebP。先阅读[执行映射](references/host-tools.md)与[分批交付](references/batch-workflow.md)，推荐类目时参考[场景与载体矩阵](references/mockup-matrix.md)。

1. **维护本聊天的品牌信息。** 查看设计师提供的 Logo，记录真实资产 ID、版本、图形结构、比例及字标。整理品牌名、行业与细分类目、受众、标准色原值、辅助色、材料工艺和设计约束。资料沿用用户已给出的内容，关键项待补充时集中确认。母版待提供时先请求 Logo；用户另行要求设计 Logo 时按该范围处理。
2. **推荐整套路线图。** 根据“行业 × 场景 × 用途”选择四至六个有实际价值的场景，为每个载体说明用途与推荐理由。默认规划约 18 张图片、三批交付，每批 4–6 张，数量和优先级服从用户指定范围及当前预算。
3. **执行当前批次。** 资料齐全时，简述整套路线图及本批清单后开始首批。先从 Logo 提取辅助图形与版式语言，再完成高频场景应用；后续批次逐步覆盖经营、传播、活动、礼赠或空间等适用场景。按分批交付规则维护计划与进度。
4. **带图延展。** 每项生成传入原 Logo 和用户已采用或已确认计划中需要沿用的视觉母版，保留图形、字标、比例与标准色关系，按载体表现材质和光照。独立项批量生成，依赖新母版的项在母版就绪后执行。
5. **交付本批。** 生成后由系统根据本轮节点缩略总览统一审查一次，关注配色、整体构图和明显问题；不逐张放大自检，不自动修复或复审。细小笔画、文字和工艺精度看不清时列为待核实，保留全部图片供用户继续指定修改。
6. **给出下一步。** 每批结束汇报本批与累计完成数量，列出下一批的场景、用途、具体载体和张数，并提供简短续接指令。此时完成本次回复；收到用户“继续”后，根据已保存路线图推进下一批。修改请求优先调整相应内容，再接续路线图。

本批完成条件：本批约定图片齐全、品牌资料和母版一致、文字准确、文件可下载，下一批建议明确。整套完成条件：路线图中的约定场景均已交付，并给出按场景整理的最终索引。

# 图文分镜

| 页 | 内容职责 | 视觉职责 |
|---|---|---|
| 01 | 一句话吸引目标读者 | 一个大主体、短标题、充足留白 |
| 02 | 展示阅读价值 | 具体场景或有依据的问题 |
| 03 | 传达核心内容 | 清楚呈现关键步骤、功能或特色 |
| 04 | 提供细节与证据 | 用户资料、真实图或标明来源的概念图 |
| 05 | 汇总和行动 | 可用清单、保存提醒或合适互动 |

页数和内容按用户范围调整。每页记录 page、headline、body、asset_refs、layout、alt_text、fact_sources。AI 概念素材在正文及适当页脚说明；事实性信息附来源，待核实内容明确标记。

沿用同一产品或 IP 母版、比例与配色，每页输出独立图片。逐字核对文字，再检查实际图片中的字形、裁切和清晰度。

虚构示例：用三页展示湿地文创 IP——“把湿地装进口袋”“从一片叶子开始”“让灵感走进日常”，内容按概念设计案例呈现。

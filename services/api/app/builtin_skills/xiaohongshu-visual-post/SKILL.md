# 小红书图文创作

用图像模型生成每页完整图文，按顺序交付独立 PNG/JPEG/WebP，附发布文案。阅读[执行映射](references/host-tools.md)，规划页面时参考[内容分镜](references/storyboard.md)。

1. 明确受众、主题、内容目的、已有事实和素材。用户提供的资料作为事实依据；虚构演示、AI 概念和产品状态按实际情况标注。
2. 按用户页数安排内容；需要建议时可采用三至五页：封面主张、场景或问题、核心内容、细节、行动。每页表达一个重点，画幅统一，默认建议 3:4 竖版。
3. 先写每页准确标题与正文，再确定主体、版式和留白。封面标题可先采用 8–16 个汉字，按实际可读性调整；封面主题与后续内容对应。
4. 用图像模型生成包含图片、标题、正文和版式的完整页面，传入实际产品、IP 或 Logo 母版。提示词逐字列出文案，控制信息密度；放大核对中文、价格与数字，准确文案另以文字保留。
5. 逐页检查产品外观、角色比例、配色、字体层级和页码。手机缩略查看主题，放大核对文字、裁切及对比度；保留合格页面，修正对应问题页。
6. 顺序展示每张完整图文，提供独立下载，并附 2–3 个标题备选、一份正文及相关标签。文案承接图片内容，商业或 AI 属性按实际情况注明。

完成条件：约定页数齐全、主题与内容匹配、每页可读、事实和数字有依据、标题正文标签可用。

# 点位与路线规则

台账字段：id、中文名、英文名、类别、坐标与坐标系、资料来源、确认状态、安装点、观察朝向、牌型、目的地列表、距离及依据。未知距离写 null；无障碍与安全路径标识采用已核实资料。

先验证 ID 唯一、连线端点存在、必需节点可达，再将固定点位、底图和路线清单作为生成依据。允许为可读性调整视觉间距，始终保持台账规定的道路连接。非等比例说明仅在正式规范或用户明确要求时进入地图；待核实路线不编入生产图像，统一列在节点制作说明中。

虚构测试：台账仅包含 E—V、V—B、V—L 三条连线。E 为入口，V 为游客中心，B 为观鸟台，L 为湖畔；在该示例坐标中，E 向北到 V，V 向北到 B、向东到 L、向南回 E。生成图应完整保留这三条连线及其方向关系。

实际项目使用项目底图和点位台账；风格探索阶段也交付无概念角标、无占位文字的干净图像，未决参数保存在节点制作说明中。

# 景区导览系统设计

以项目点位和路线资料为依据，用图像模型生成各项独立 PNG/JPEG/WebP。阅读[执行映射](references/host-tools.md)与[点位和路线规则](references/wayfinding-data.md)。

1. 整理底图、边界、入口、景点、公共服务、道路连接、方向与安装点。记录距离、无障碍路线和开放状态的来源；资料待补充时，只制作不依赖未知参数的视觉方向，待确认项写在图像节点底部，不在图片上加入概念示意角标或占位文字。
2. 建立统一点位台账，确定名称、编号、图标、信息层级、材质和配色。按用户范围选取总览、方向分流、目的地识别等牌型。虚构测试可参考[示意数据](assets/example-site.json)。
3. 分别生成总览图与各牌面正视图，传入实际底图和风格母版，提示词列明文字、点位及连线要求。逐条对照台账核对路线；非等比例等正式使用所必需的说明，仅在用户或适用规范明确要求时进入牌面，否则放在节点制作说明中。
4. 根据安装点和观察朝向确定箭头，“您在此”对应实际安装位置。距离、北箭头、比例尺、无障碍及疏散信息采用已核实资料；待核实项不编入牌面，在节点制作说明中列出。公共信息符号使用业主或适用标准提供的资源。
5. 引用确认的牌面图片生成安装场景，保持去向、箭头、文字与版式一致，体现材质、尺度和环境关系。
6. 核对点位、方向、名称、信息密度、字色对比与远读性。逐张交付总览图、牌面和场景图片，附所需点位台账与材质尺度说明。实施阶段的结构、基础和照明由专业方核实。

完成条件：资料状态明确、各牌共用台账、路线连接经过核对、约定图片齐全、场景可追溯至实际牌面。

# 原创 IP 形象设计

用图像模型制作角色与应用图片，逐张交付 PNG/JPEG/WebP，附角色设定。阅读[执行映射](references/host-tools.md)，建立设定时参考[角色设定表](references/character-bible.md)。

1. 提取项目目标、受众、品牌或主题元素及已有视觉。记录资料来源，区分项目事实与设计演绎；虚构案例明确标记为设计示例。
2. 选择一个主载体及一至两个主题识别线索，确定性格、轮廓、头身比、配色、服饰与配件位置。已有 IP 使用用户指定母版。
3. 先生成清晰的角色母版，再引用实际资产制作约定视图。左右配件按角色自身方向描述，逐视图核对结构，作为后续延展的设定参考。
4. 根据用户范围生成动作表情与应用效果。需要建议时，可选欢迎、互动、工作、休息等动作，以及贴纸或摆件应用；每项沿用同一母版及固定特征。
5. 由系统在本轮节点缩略总览中统一审查可见的脸型、比例、配件、色彩与肢体结构。不逐图自检或自动修复复审；看不清的身份细节列为待核实，用户指定修改后再处理。
6. 逐项交付约定的母版、视图、动作和应用图片，附固定特征、可变特征及使用说明。用户只需第一稿时，交付母版与简短设定。

完成条件：主题线索有依据、轮廓可识别、各视图与动作保持角色身份、应用引用实际母版。

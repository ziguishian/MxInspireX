# 角色设定表

| 项 | 记录内容 |
|---|---|
| 地域依据 | 用户资料、可信来源或虚构样例标记 |
| 核心符号 | 物种或器物、轮廓、一句性格 |
| 结构 | 头身比、眼距、嘴型、肢体数量；角色自身左右 |
| 调色板 | 主色、辅色、材质、授权单色版 |
| 固定特征 | 脸型、饰品数量、佩戴位置、标记 |
| 可变特征 | 动作、表情、场景、应用材质 |
| 母版 | 当前版本、真实资产引用 |

提示词以实际角色为身份参考，保持脸型、比例和配件，按需求改变动作；全身完整入画、背景清晰、光照统一。背面按角色结构展示后脑、背部与配件背侧。高要求视图可分开生成，核对后组合设定板。

虚构示例：湿地白鹭角色，白色圆身、金黄短喙、绿色叶帽、一枚圆徽章和绿色斜挎包。逐视图、逐动作对照这些固定特征。

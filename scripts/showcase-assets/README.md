# 演示素材

`manifest.json` 记录用户提供的 16 张原图如何进入七个演示案例，以及作者/来源信息。原图不在此目录，也不得直接用作无水印交付成品。

`clean/` 只放逐张去水印且经人工对照验收的成品，文件名必须与清单一致。仅去除平台角标、摄影工作室叠加署名等水印；产品商标、包装文字、纹样和真实奖项标识保持原样。若局部修整改变器形、材质、文字或画幅比例，该张不能进入 `clean/`。

`node scripts/import-showcase-additions.mjs --workspace <工作区> --api <已运行的 API>` 会先核对所有成品文件，再写入项目。文件缺失时不创建空项目，也不会将带水印原图替代成品。原图及修整记录由素材提供者保留；画布节点和资产元数据保存来源署名。

`shan-ming-v1/` 是独立的山茗资料包：7 张山茗品牌与包装视觉图、2 张明确标记为其他品牌的参考图，均是用户提供的原文件副本，没有修改原图。`node scripts/import-shan-ming-showcase.mjs --check` 校验九张图的 SHA-256；正式导入时使用 `--workspace <工作区> --api <已运行的 API>`。山茗卡片取代首页的山砚卡片，但山砚项目及其数据不删除。山茗图中的尺寸、刀线和出血仅按原图呈现，不能视为已核准的可投产工程文件。

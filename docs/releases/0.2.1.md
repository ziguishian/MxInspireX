# MxinspireX 0.2.1

## 下载

Windows 10/11 x64：下载 `LangjuAgent-0.2.1-windows-x64-setup.exe`，按向导安装。首次使用需在“模型与连接”配置自己的 API Key；安装包不包含账号、模型额度或个人项目。

## 本次更新

- 改进多轮设计与交付调度，保留成功产物，避免同一交付重复生成。
- 完善节点底部生成、上游引用、连线删除、撤销与持久化；生成前显示简洁交付摘要。
- 增强原结果取回与计费状态提示，未知结果不自动重发。
- 精简模型选择与 Agent 回复，增加外观、常规设置和工作区存储选项。
- Windows 安装版支持从本仓库 Releases 检测新版本；仅用户确认后下载和重启安装。
- 更新 GitHub 产品介绍、FAQ、公开产品事实与搜索资料索引。
- 打包前执行类型检查、单元测试、隔离 API 与 Electron 画布回归。

## 更新与限制

- 本次发布 Windows x64 完整版，其他平台未在本次构建验证。
- 当前无 Authenticode 发布签名，Windows 可能提示未知发布者；不宣称已完成签名或 SmartScreen 认证。
- 旧版安装包如无更新功能，需要手动安装此版本；项目数据仍保存在原工作区。
- 本地优先不等于完全离线，云模型会接收本次任务必要输入并按服务商规则收费。
- 自动测试使用隔离数据与模拟服务；真实模型能力和可用性取决于自己的服务配置。
- `latest.yml` 与 `.exe.blockmap` 用于更新器，用户只需下载安装包。SHA256 校验值见 Release 附件。

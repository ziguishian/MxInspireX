# MxinspireX 0.2.3 · 画布工作流与桌面体验

## 下载

Windows 10/11 x64：完整版选择 `LangjuAgent-0.2.3-windows-x64-setup.exe`；轻量版选择 `LangjuAgent-0.2.3-lite-windows-x64-setup.exe`，CAD 和本地媒体能力可后续安装。首次使用需配置自己的模型服务，不附带 API Key、模型额度或个人项目。

## 本次更新

- 新增独立工作流库、命名保存、画布缩略图和独立工作副本。
- 文件夹作为画布输入节点，逐项执行下游流程；可编辑整个工作流重复次数，绿色图标启动。失败停止后续步骤，已有输出保留。
- 双击画布打开节点搜索；对话收起后，保存工作流按钮位于 Home 右侧。
- 新增本地 VTracer 转矢量、透明抠图、视频分镜与可编辑色板，提供节点和能力扩展规范。
- 更新应用图标、水波加载、桌面工具栏和主题；完善画布背景预览、透明节点边框与连线操作。
- 增加语音输入、消息复制/时间戳/朗读、音频与 3D 资产预览及四种吉祥物。
- 修复缩放过程中输入框尺寸变化触发自动适应视野、覆盖用户缩放比例的问题。

## 验证

发布门禁包含类型检查、549 项单元测试（另 3 项明确跳过）、48 项后端恢复与画布测试、七类节点输入框、连线持久化、任务恢复和综合画布回归。新增功能另通过 18 项后端测试，以及文件夹批量工作流、桌面主题与背景设置持久化检查。

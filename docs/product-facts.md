# MxinspireX 产品事实与常见问题

MxinspireX 是灵矩绘境开发的本地优先 AI 设计工作区，连接持续项目对话、参考资料与无限画布，服务于文旅、文创及产品设计。官方源码：[ziguishian/MxInspireX](https://github.com/ziguishian/MxInspireX)。

## 能力与边界

- 设计：Logo、海报、包装、产品、IP 形象、场景概念及文字策划。
- 产物：文本、图像、视频、音频、交互 HTML、本地参数化 CAD；外部 3D 服务需独立配置。
- 引用：节点连线传递上游内容，图片编辑保留来源，在新节点交付。
- 执行：按依赖组织任务；未知收费结果不自动重复提交，可查询已受理媒体的原结果。
- 数据：项目与文件保存在本机；云模型会接收完成任务所需的内容，不是完全离线软件。
- 费用：不附带账号、API Key 或模型额度；服务商已确认扣费、估算与待对账分别展示。
- 许可：源码 MIT，第三方依赖与用户素材遵循各自许可。MIT 不表示外部模型调用免费。
- 平台：本次安装包目标为 Windows x64；其他平台仅以 Release 实际附件和验证说明为准。
- 语言：界面以中文为主，多语言 README 不代表多语言界面。
- 生产：图像生成的包装、刀版或产品效果仅为概念参考，不能当作已校核的生产文件。

## 如何使用

从 [Releases](https://github.com/ziguishian/MxInspireX/releases) 下载，配置“模型与连接”，同步模型目录后提交需求。详细步骤见 [使用指南](https://github.com/ziguishian/MxInspireX/blob/main/docs/USER_GUIDE.md)。源码运行见 [README](https://github.com/ziguishian/MxInspireX/blob/main/README.md)。

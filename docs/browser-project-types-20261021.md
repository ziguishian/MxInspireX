## 已修复

1. 返回首页后，旧项目任务观察状态不再阻塞新建项目；后台任务继续运行。
2. 单张 Logo“方案图”保持简单单图流程；“不做研究/直接完成单页”不再误触发参考搜索。
3. CAD 子进程有隔离临时 HOME；中文相邻 CAD 正确识别交付要求，避免构建失败误标完成。
4. 同一任务、同一视频节点/交付项即使改写提示词也复用原 job，重启后仍有效；单视频受理后不再补跑模型等待。
5. EvoLink 默认 Seedance 家族按本地目录映射文生/图生变体，手动选模不被覆盖。默认静态镜头改为跟随描述。
6. 音频、视频本地配置失败有针对性的中文说明。
7. HTML 预览内部锚点滚动不会把宿主应用加载进 iframe；沙箱/CSP 未放宽。
8. 已保存的迟到图片在全部交付通过后同步任务完成状态，同时保留原失败原因。

## 仍需处理

- 音频及 3D 需要可用的模型/服务配置，现有 Key 不能证明这些能力可用。
- EvoLink 文本历史续接的跨资源 400，以及流式连接中断仍可能发生。
- 图片首次下载失败尚无产品内的一键取回入口；本次用定向脚本查询原任务并恢复。不能把手动恢复视为正常自动流程通过。
- 视频防重与默认路由已通过隔离回归；没有为了验证修复再产生第三笔视频费用。

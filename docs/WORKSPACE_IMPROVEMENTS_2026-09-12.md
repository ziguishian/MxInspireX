## 恢复边界

- 连接重试只读取原任务；“继续原任务”复用原 ID 和现有执行记录，不创建第二个任务。
- 已保存的工具回执和产物继续使用既有恢复机制。上游是否已收费不明确的请求，不保证能自动重发；仍由已有的未知请求保护规则处理。
- 服务重启入口为 `python -m app.server`。开发重载、桌面启动和 sidecar 统一使用；保留 stock uvicorn 启动时的关闭信号兼容处理。
- 本地草稿依赖对应浏览器/桌面的存储空间，不跨设备同步。磁盘保存失败会显示提示。
- 内容依据检查是有限的技术参数筛查，`source_matched` 仅表示能在输入资料中找到对应数值，不代表现实世界真实性或完整语义一致；审查 Agent 仍负责上下文及语义核对。
- 本次内容检查影响后续交付验收，不自动改写或为旧产物补造来源。

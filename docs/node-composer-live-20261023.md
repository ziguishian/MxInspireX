## 根因与修复

截图任务 `beecdcf3-568e-4595-b361-d52c4c3faa7a` 的原始错误为 EvoLink HTTP 400：GPT Image 2.5 Sunburst 不接受 `background=auto`。EvoLink 参数适配现在对 2.5 Sunburst/Flare（含日期版本）省略自动背景参数，使用服务默认值；明确的 transparent/opaque 保持不变。真实“小狗”用例已通过。

## 上游更新、重连与重试回归

补测发现：提交任务之后、首次预检之前，上游图片被替换时，旧资产仍可能通过预检。原因是版本收集只包含当前资产与请求匹配的节点，变更节点反而被排除。现在图像预检和其他节点生成入口共用 `node_context.check_canvas_inputs`，校验显式上游节点是否存在、就绪、图片资产是否仍对应提交快照，以及内容是否与已读取版本一致。失效输入在调用 Provider 前阻止，移动节点不视为内容修改。

- Electron + Vue Flow 自动化保持输入框打开，修改上游文字后提交；断开旧连接、连接新图片并替换新图片后重试，验证最新文本与资产 ID、旧引用已移除、连续点击仅提交一次、源节点不变、已有输出不覆盖。
- 后端覆盖首次预检前替换、清空、生成中和删除上游，七类生成工具的文本版本检查，以及明确失败后的新请求、旧请求重放、重试重复提交的隔离与去重。
- 本轮结果：真实组件自动化通过；4 个相关 Python 文件 93 项通过；前端全量 87 文件 508 项通过、3 项既有跳过。这些生命周期测试使用模拟 Provider，没有新增付费生成请求，不代表额外完成了真实供应商端的故障注入测试。

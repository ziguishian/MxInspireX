## 实测中修复

- 参考图上传失败时，生成尝试已终止但收尾文字误称作品保存。统一终止文案按失败/未知回执展示；交付有问题且没有就绪资产时返回失败。停止重复生成的逻辑保持不变。
- 同一个计划校验错误会在后续成功的 `design_state` 和进度说明回合继续消耗纠错预算。改为按失败回执所在回合计数，正常前置修复不重复计数；重复失败仍最多修正两轮，计数仍持久化。
- 完整返回的文本响应 ID 未清除，后续本地校验错误误标成已受理断流及费用未知。现在完整响应结束后清除活动 ID，保留原始用量；真正断流仍保留未知结果保护。
- 旧计划触发 `design_spec_required` 后恢复规划工具，以便修正实际缺项。

首饰包装测试曾有一次参考上传失败（生成尚未提交），以及一次本地纠错计数提前结束（6 次文本响应完整返回，没有图像调用）。原任务与原计费记录保留，未改写失败历史。修复后沿用已保存首图继续测试。

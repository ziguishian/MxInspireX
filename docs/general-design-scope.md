# 通用设计定位（2026-10-24）

MxinspireX 面向通用设计任务，由当前用户需求决定领域、受众、用途、风格和交付范围，不将某个行业作为默认前提。

本次覆盖主 Agent 系统指令与技术参数／改图示例、图像评价角色、原创 IP／空间导视／社交图文等内置技能正文和说明、项目名称与定时任务占位文案、产品元信息、公开页面、多语言 README 和开发文档。原有节点原样生成边界不变。

图像评价保留 `culturalRelevance` 历史字段，但明确其语义为主题与需求契合度；不要求作品具备文化元素。仅测试模式的固定评分也不再对特定主题关键词加分。

参考库默认分类覆盖多个领域，不再置顶旧行业。已有素材分类、用户自定义分类、历史项目和案例不改写；旧分类别名继续兼容。内置技能稳定 ID 不改名，变更源包提高 revision 并更新 SHA-256；原有安装机制只升级未被用户修改的包，不恢复已卸载技能、不覆盖旧任务绑定。

验证：构建、类型检查、Node worker 语法检查通过；公开页面 5 项测试通过；内置技能与参考库回归 51 项通过。3 项参考选择流程测试失败（刷新候选、上传后恢复候选、非图附件选图），在隔离进程加载 HEAD 的参考库实现后同样复现，因此并非本次分类调整引起。测试使用隔离目录与模拟服务，没有调用收费模型。应用已在原工作区重启，健康检查正常，参考分类接口已返回通用分类。

# 无限画布的框选、移动与对齐

在画布空白处按住鼠标左键拖动即可框选，与框选区域相交的节点会被选中。按住 Shift 框选可追加节点；Shift、Command 或 Ctrl 加单击可添加或取消单个节点。点击空白处或按 Esc 取消选择。中键拖动、空格加左键拖动仍用于平移画布。

选中多个节点后，拖动任一选中节点的可拖动区域，或选区上方的“拖动选区”手柄，即可整体移动。节点间距保持不变。方向键微调 1 个画布单位，Shift 加方向键微调 10 个单位；输入框中的方向键仍用于编辑。

多选时，工具条显示在全部选中节点的整体边界上方，并按整体宽度水平居中。移动节点、对齐、缩放或平移画布时，工具条随选区更新位置，按钮保持屏幕尺寸。工具条提供左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐，以及水平、垂直等距分布。对齐至少需要两个节点，等距分布至少需要三个节点。对齐依据实际内容预览框，不包含标题、提示词编辑器或警告信息；操作保持当前缩放和视口。

整组移动和一次对齐各作为一个批量画布编辑保存，可用 Command/Ctrl + Z 撤销，用 Command/Ctrl + Shift + Z 重做。框选本身不写入后端。保存失败时重新读取已保存画布；包含生成中锁定节点的选择不能部分移动或对齐。画布框选不会顺带选中连接到区域外的连线。

验证入口：`npm run test:canvas-selection`、`npm run test:canvas-snap`、`npm run test:canvas-workspace`。使用真实 Chromium 鼠标和键盘事件，覆盖三种缩放、网页 iframe、追加选择、批量保存、撤销重做、对齐、锁定节点、失败恢复以及窄窗口布局；全部使用隔离的模拟画布。

## 手绘画板节点

右键 → 新增节点 → 画板（双击空白处也可创建）。画板是 `kind=image`、`editor=drawing` 的可编辑图像节点，支持鼠标/触控笔自由绘画、橡皮、颜色、粗细、撤销/重做。顶部“清空”清除笔迹但保留节点，可撤销；“删除”仅删除当前画板及相连连线，复用画布删除与撤销机制。删除等待已提交的笔迹保存完成，取消尚未提交的自动保存，成功后清除本地草稿；失败则保留画板。节点缩放和画布缩放不会改变笔迹坐标；拖动标题可移动节点，绘画区域不触发节点拖拽或画布平移。

笔迹按 1024×768 白色画板坐标保存，通过 `PUT /api/projects/{project_id}/canvas/{node_id}/drawing` 自动提交。请求携带 `baseRevision` 与绘画文档，服务端验证项目、节点、活动任务锁、版本和坐标后渲染真实 PNG。节点保留可编辑笔迹，每次保存的 PNG 是不可变资产，旧引用和旧版本不受后续绘画影响。空白/清空画板没有可引用资产。保存失败保留本地草稿并支持重试；版本冲突不覆盖其他页面的内容。

点击“引用布局”放入对话，或从画板输出端连接到图像节点后输入生成要求。保存未完成时阻止引用与提交，避免使用旧 PNG。图像生成采用 `reference_analysis.mode=layout`，模型接收真实草图并遵循结构布局要求；生成结果新建节点，保留画板及笔迹。画板参考摘要不把整段笔迹坐标发送给 Agent。

验证：`npm run test:drawing-canvas` 使用隔离 Electron/Vite 和模拟 API，覆盖真实鼠标输入、缩放、自动保存、撤销/重做、保存失败和引用生成；`test_drawing.py` 验证 PNG 内容、项目范围、版本冲突及真实工具链 Provider 输入。


## 作品版本对比与采用

画布操作菜单或多选工具栏可打开 `CanvasVersionCompare.vue`，选择 2–4 个已有作品并排查看图像、文本、HTML、视频或音频。HTML 复用受限预览沙箱。选择“采用此版”仅切换本次对比所选作品的 `data.adopted/adoptedAt`，保留其它作品和连线；通过原有增量变更、内容版本检查和撤销历史保存。生成中锁定的节点不能切换采用标记。

“从此版继续修改”将指定作品作为明确引用并聚焦对话输入框；不会立即提交生成。后续图像修改仍遵循保留原图、生成新节点的规则。节点标题显示“已采用”；Agent 的节点视图也包含采用标记，不能将未采用的历史生成图冒充用户确认版本。

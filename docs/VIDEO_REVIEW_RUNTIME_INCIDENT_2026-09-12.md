# 视频完成后最终审查启动失败

## 结论

视频生成和浏览器预览已通过，失败发生于启动最终审查进程。运行中的发布目录被重新打包删除、重建，Python 后台仍持有已被解除链接的工作目录。`DesignRuntime.run()` 调用 `Path.cwd()` 产生 `FileNotFoundError`，被范围过大的异常捕获误报为“找不到 Node.js”。并非视频模型生成失败，也不是视频审查认为画面不合格。

## 修复

1. Agent worker 从独立任务目录启动，不再读取后台继承的应用工作目录。
2. 仅对进程启动异常分类，区分缺少执行文件、缺少工作目录等本地运行时问题；不再把它们算作模型错误或触发备用模型重试。
3. 用户可以恢复原失败任务；已进入最终审查的任务保持 `deliveryReviewOnly` 和已保存产物，继续审查，不重发视频生成请求。兼容旧版“找不到 Node.js”记录。
4. 前端将本地运行时错误展示为“本地执行环境需要恢复”，操作改为“继续原任务”。
5. 打包覆盖发布目录前检查运行中的应用和后台进程；仍在使用该目录时停止覆盖。
